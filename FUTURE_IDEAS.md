# Future Enhancement Ideas

This document contains enhancement ideas that are not currently prioritized for GitHub issues but may be considered in the future.

---

## Document Formatting Options

### Page Numbering Styles
Different page numbering formats (1, i, a, Roman numerals)

### Multi-Column Layout
Support for 2–3 column layouts for specific sections — common in scientific and academic documents.

---

## Output Customization

### PDF/A Compliance
Generate PDF/A format for long-term archival

---

## Performance Optimizations

### Incremental Conversion
Only reconvert changed files in batch mode

---

## Web Service / Container Variant

### Browser-Based Conversion UI
A containerized web application where users upload one or more Markdown/HTML files, configure conversion options via a GUI, and receive the resulting PDF(s) — offering md-to-pdf as a self-hostable service.

---

## Accessibility Features

### WCAG Compliance & Screen Reader Support
Ensure PDFs meet WCAG 2.1 AA standards and are optimized for screen readers.

### Alt Text for Diagrams
Automatic or manual alt text for Mermaid diagrams and images.

### Language Support
Proper language tagging in PDF metadata for multilingual documents.

---

## Developer Experience

### Validation Mode
Validate Markdown syntax and structure before conversion (complements existing `--strict` image validation).

### Version Watermarking
Automatic version numbers and timestamps — useful for draft and review workflows.

---

## Content Processing Features

### Front Matter Support
YAML front matter for document metadata and per-file configuration.

---

## Notes

These ideas are collected for future consideration. They may be promoted to GitHub issues based on:
- User demand and feedback
- Strategic alignment with tool vision
- Implementation feasibility
- Resource availability
